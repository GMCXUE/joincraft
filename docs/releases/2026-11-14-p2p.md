# 0.9.28：P2P 与客户端交互

源码检查点：`ff0c2b1`。Windows 安装程序和签名应用内更新均已发布至正式下载入口，客户端可从 0.9.27 检测到 0.9.28。

- MC 联机优先 P2P，协商未就绪时使用原有中继；允许房间内逐成员混合链路。
- 游戏库保存「自动 / 仅服务器中继」偏好，显示实际连接方式与测得的直连 RTT。
- 优化游戏库、存档、启动、安装取消和应用内更新反馈，并增加 GitHub 入口。
- 直连中断会关闭当前游戏流；新连接使用中继，首版不承诺无感切换。

验证：296 项源码回归、120 项安装载荷测试、辅助组件模拟与 Forge 发现通过。EXE 与更新包签名、大小、SHA-512、共同载荷及 Go 解包校验通过；正式域名下验证协商、两条直连与一条中继的混用、故意阻塞协商后的回退及离房撤销。验证使用合成 MC 协议和同机 Electron 对端，测试房间已关闭，会话已退出，不代表跨网络 NAT 或 Windows 真实游戏已经验收。

公网安装程序与应用内更新包完整下载、签名清单、更新提示和 Range 下载均通过；保持原有 HTTPS 入口与语音链路。跨网络和 Windows 进入真实世界仍需实测。
