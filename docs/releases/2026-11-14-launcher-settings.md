# 0.9.30：返回导航与启动设置

源码检查点：`0e97153`。网页资源、Windows 安装程序与签名应用内更新已发布；0.9.29 客户端可检查更新至 0.9.30。

- 返回入口固定在游戏库左下角，先回首页，再保存设置；未完成表单、保存失败或后台任务不阻止导航。
- 首页直接保存离线玩家名，跨整合包复用；微软登录入口、设备码和账号状态也放在首页。当前发行配置未启用微软应用，真实授权仍待配置后验收。
- 手动 Java 选择按整合包保存，首页和房间启动保持一致。
- 版本设置新增折叠的高级选项：JVM 参数、游戏参数和窗口尺寸/全屏，显式保存并接入真实进程参数；保留专用的账号、内存、目录和联机目标设置。
- 附加参数按字面数组解析引号及 Windows 路径，不经 Shell；内存重新计算后仍保留高级参数。
