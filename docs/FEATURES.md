## 当前限制

- 默认仅监听本机；房间、图片、成员和设备会话已保存至 SQLite，重启保留。
- 有设备鉴权、30 天空闲过期和房间权限；已支持用户名密码跨设备登录；密码找回与可信游戏在线状态待补。
- 房间密码以加盐 scrypt 摘要存储；设备与 IP 限流保存在数据库，状态通过 WebSocket 推送，旧 SSE 入口保留兼容。
- Java TCP 中继与本机连接地址已实现，尚未验证真实 MC、Windows 与异地网络；游戏启动 / 安装、模组分发及 Java 检测未实现。
- 已有好友私聊、房间群聊和独立语音分组；移动原生 App 未实现。语音已做本机模拟音频测试，真人麦克风与异地网络待验证。

## 房间语音首版

| 位置 | 功能 | 行为 |
| --- | --- | --- |
| 房间聊天 | 文字群聊 | 房间成员可用；实时同步、未读、分页、草稿及幂等重试，每房间保留最近 5,000 条 |
| 左侧语音分组 | 游戏 | 新旧房间均自动提供一个默认分组，不可删除 |
| 分组标题右侧 ＋ | 房主建组 | 最多 8 组，独立音频；重命名、删除额外分组 |
| 分组行 | 加入 / 切换 | 一次只加入一个组，切换页面保留语音，切换分组先退出旧组 |
| 底部语音栏 | 麦克风 / 收听 | 默认不开麦；关闭收听同时静音，恢复收听不自动开麦 |
| 语音设置 | 音频设备 / 成员音量 | 选择输入；支持的浏览器可选输出；其他成员音量仅影响本机 |
| 分组成员 | 正在说话 | 真实 LiveKit 参与者和音频活动，不把房间成员数当通话人数 |
| 右侧成员栏 | 在线 / 语音状态 | 页面在线通过有效 WS / SSE 会话判断，不代表 MC 游戏在线 |
| 成员右侧菜单 | 房主管理 | 限制麦克风、允许自行开麦、移出语音并禁止重进 60 秒 |

不包含视频、屏幕共享、录音、频道嵌套、按键说话或移动端后台通话。

## 客户端更新通知

客户端全局通知可检查正式版本；主进程下载、SHA-512 校验、进度、取消与失败重试，下载完成后由用户确认重启安装。正在启动 / 运行游戏时不能安装，普通退出不自动安装。Windows NSIS exe、macOS dmg + zip 及 GitHub Draft Release 工作流已配置；正式签名、首次发布及两版升级实测仍待完成。

更新入口位于桌面客户端全局右上角铃铛，房间页和游戏库均可打开独立通知窗口；每个新版本只自动提醒一次，记录跨重启保存。普通网页没有更新提醒和入口。

## 0.9.19 房间整合包安装
- 支持标准 Modrinth .mrpack v1（清单包最大 16 MB），识别原版 / Fabric / Forge / NeoForge / Quilt 依赖，使用官方源安装游戏与 Java；CurseForge ZIP 和任意目录打包分发尚未支持。
- 游戏库增加安装整合包与安装目录选择，托管实例独立存储并跨重启保留；退出房间不删除安装，个人存档保留。已有 PCL 实例仍可添加。
- 房主可从本机已安装托管实例或 .mrpack 设置房间版本；成员受权限校验后获取相同清单，在自己的电脑下载模组与依赖。Web 端不显示本机安装入口。
- 安装显示当前阶段、当前文件、文件/阶段字节数、文件数量、速度与本阶段剩余时间；无可信总量或处理步骤不编造 ETA。可取消、重试、复用已验证缓存；安装失败不注册半成品，已修改实例重新安装为独立副本。
- 首次从房间启动先进入游戏库确认玩家名和内存；成功启动后保存设置，再从房间直接启动。微软账号仍沿用已有配置状态，不替代 joincraft 登录。
- 数据库由 5 增至 6，仅增加房间清单存储；成员下载权限跟随房间成员关系。Windows 真实游戏需后续实机验证，本次使用模拟游戏文件与下载进行流程验证。
