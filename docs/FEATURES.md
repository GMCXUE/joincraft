# 功能清单 · v0.8 Java 联机

## 已实现，可在本地体验

| 位置 | 功能 | 当前行为 |
| --- | --- | --- |
| 左侧房间栏 | 房间列表与切换 | 支持多个房间，选中有绿色描边；图片优先，无图显示名称简称 |
| 左侧「＋」 | 加入房间 | 6 位房间号 + 可选密码，无审批，成功后自动进入并添加到左栏 |
| 添加窗口的创建标签 | 创建房间 | 名称、图片、可选密码、人数上限，创建时无需先填写游戏端口 |
| 房间概览 | 房间信息与邀请 | 房间号、复制、介绍、环境摘要、真实操作记录 |
| 邀请窗口 | 本机多人测试 | 访客新标签页独立会话，密码另行告知，不展示已保存密码 |
| 成员列表 | 已加入成员 | 昵称、房主 / 成员角色；不等同于游戏内在线状态 |
| 游戏环境 | 配置与查看 | 房主填写 MC 版本、加载器、局域网端口；成员只读 |
| 游戏环境 | 旧实例兼容 | 可选取此前保存在本浏览器的实例配置，不扫描游戏文件 |
| 房间设置 | 修改房间信息 | 名称、介绍、成员上限、图片；仅房主可改 |
| 房间设置 | 密码管理 | 保留、更换或取消密码；变更仅影响后续加入，现有成员保留 |
| 图片选择 | 房间头像 | PNG/JPEG/WebP，浏览器裁剪压缩为 192px 正方形，可移除 |
| 概览 / 设置 | 退出或关闭 | 成员退出后图标移除；房主关闭使房间号失效 |
| 左下角 | 个人设置 | 修改展示昵称，非 MC 账号登录 |
| 页面整体 | 响应式 / 键盘 | 窄屏房间导航横排，表单、原生弹窗与可见焦点 |

## 当前限制

- 默认仅监听本机；房间、图片、成员和设备会话已保存至 SQLite，重启保留。
- 有设备鉴权、30 天空闲过期和房间权限；已支持用户名密码跨设备登录；密码找回与可信游戏在线状态待补。
- 房间密码以加盐 scrypt 摘要存储；设备与 IP 限流保存在数据库，状态通过 SSE 推送。
- Java TCP 中继与本机连接地址已实现，尚未验证真实 MC、Windows 与异地网络；游戏启动 / 安装、模组分发及 Java 检测未实现。
- 已有好友与文字私聊；语音和移动原生 App 未实现。

## v0.6 好友与私聊

- 尚未提供好友删除 / 拉黑、群聊、文件图片发送、语音或端到端加密。
