# 成员加入游戏的显示条件

不增加房间准备面板。已有「游戏联机」区仅在房主成功开房后显示成员加入按钮；房主离线、等待世界载入或连接断开时，显示对应等待文字。房主自己的开房和停止操作保留，成员仍可先安装或同步整合包，也能退出房间启动模式后从游戏库单独游玩。

在线以房主已认证的游戏控制连接为准，不把房间成员数量或网页在线人数当作游戏可加入状态。服务端连接摘要新增 `hostOnline` 和 `joinable`；只有房主游戏连接为打开状态、会话有效且 MC 就绪后，`joinable` 才为真。成员新连接票据也检查相同条件。

网页组件、旧式整合包启动入口和新版客户端共用显示条件。客户端选择房间、发起连接，以及建立隧道后、创建游戏进程前重新读取房间状态，阻止旧按钮或准备期间的状态变化继续启动。房间实时状态也会同步到已打开的成员启动设置，使按钮隐藏或恢复。该界面同步只控制可见性，不能代替主进程及服务端检查。

旧服务端没有显式字段时暂按其 `online` 状态兼容，新服务端的显式否定优先。此调整不承诺游戏启动后房主永远在线；后续断线仍由现有连接回收和重新连接流程处理。

验证覆盖离线、准备中、连接错误、已就绪、旧按钮、旧版客户端入口、房主停止、房间状态变化以及真实本地 TCP/WSS 中继生命周期。界面三状态隔离预览确认只有已就绪状态存在加入按钮，游戏库离线成员启动按钮隐藏。
