# Pixel wordmark

The lowercase joincraft wordmark is drawn as SVG outlines from the same Fusion Bold Pixel release (2026.11.10) used by the selected Chinese slogan. It retains the lowercase name and the existing green J/C connection symbol.

- Master SVG: ../../public/brand/wordmark-pixel-v1.svg.
- Generator: ../../scripts/build-wordmark.py (fonttools[woff]).
- Outline viewBox: 57 x 13, including a one-unit margin.
- Colors inherit currentColor. Header versions use the same geometry on light and dark surfaces.
- Font attribution and SIL OFL/component notices: ../../public/brand/wordmark-license.txt.
- Website/login/room/library source headers use the generated inline SVG; no browser font loading is needed for the wordmark.

The app icon, favicon and standalone J/C mark are unchanged.

The Windows 0.9.11 release carries the wordmark and notices in its local game-library header as well as the server-hosted room header.
