# Current headline typography

User-selected pairing: **Fusion Bold Pixel** with **一起上线，一起造。**

- Original: 12px proportional zh-Hans TTF WOFF2, [release 2026.11.10](https://github.com/pixel-font-studio/fusion-bold-pixel-font/releases/tag/2026.11.10).
- Unchanged source: fusion-bold-pixel-12px-zh-hans-2026.11.10.woff2.
- Modified subset family: Joincraft Bold Pixel Display.
- Published resource: ../../public/home/pixel-display-v2.woff2.
- Copyright, SIL OFL and all upstream component notices: ../../public/home/pixel-bold-font-license.txt.
- Rebuild: python scripts/build-display-font.py, after installing fonttools[woff] into an isolated environment.

The 12px pixel grid is displayed at integer multiples of 12px, with the font's own spacing, a deep forest fill and a small warm offset matching approved option A. The heading is split into two phrases on both the homepage and login illustration. UI forms retain their existing typeface.

The previous Ark Pixel subset at pixel-display-v1.woff2 and the earlier Noto subset remain unchanged at their published immutable URLs for historical clients and caches.
